# 🌡️ Thermometer & Hygrometer in C++ with ESP8266 & WS2812B Matrix

Компактний цифровий термометр і гігрометр на базі мікроконтролера **ESP8266** (Wemos D1 mini / NodeMCU), датчика **DHT11** та світлодіодної матриці **WS2812B 8x8** (64 RGB LED).

Проєкт зчитує показники температури та відносної вологості повітря і покроково відображає їх на матриці за допомогою кастомного шрифту 3x5.

---

## 🛠️ Компоненти та апаратна частина

* **Мікроконтролер:** ESP8266 (Wemos D1 mini або NodeMCU)
* **Датчик клімату:** DHT11 (або DHT22)
* **Дисплей:** Світлодіодна матриця WS2812B 8x8 (64 пікселі)
* **Джерело живлення:** 5V USB

### 🔌 Схема підключення (Pinout)

| Компонент | Пін елемента | Пін ESP8266 | GPIO |
| :--- | :--- | :--- | :--- |
| **WS2812B Matrix** | DIN | **D1** | GPIO5 |
| **WS2812B Matrix** | 5V / VCC | 5V / VIN | 5V |
| **WS2812B Matrix** | GND | GND | GND |
| **DHT11 Sensor** | DATA | **D4** | GPIO2 |
| **DHT11 Sensor** | VCC | 3.3V / 5V | 3.3V / 5V |
| **DHT11 Sensor** | GND | GND | GND |

> ⚠️ **Важливо:** Переконайтеся, що GND матриці, датчика та ESP8266 об'єднані в спільну шину заземлення.

---

## ✨ Особливості реалізації

- **Динамічна індикація:** Автоматична зміна режиму відображення кожні 3 секунди (Температура ↔ Вологість).
- **Візуальний розподіл режимів:** 
  - Температура відображається червоним кольором та символом `°`.
  - Вологість відображається блакитно-зеленим кольором та символом `%`.
- **Кастомний шрифт:** Компактні цифри $3 \times 5$ пікселів для точного розміщення двох цифр та спецсимволу на сітці $8 \times 8$.
- **Підтримка Serpentine Матриць:** Алгоритм адресації перераховує координати $(X, Y)$ для зигзагоподібних матриць, запобігаючи спотворенню картинки.
- **Обробка помилок:** При втраті зв'язку з датчиком DHT11 матриця сигналізує про помилку (переходить у пурпурове світіння).

## 💻 Необхідні бібліотеки

Для збірки проєкту в **PlatformIO** або **Arduino IDE** потрібні такі бібліотеки:

* [Adafruit NeoPixel](https://github.com/adafruit/Adafruit_NeoPixel)
* [DHT sensor library (Adafruit)](https://github.com/adafruit/DHT-sensor-library)
* [Adafruit Unified Sensor](https://github.com/adafruit/Adafruit_Sensor)

### Налаштування `platformio.ini` (для PlatformIO):

```ini
[env:wemos_d1_mini]

board = d1_mini
framework = arduino
monitor_speed = 115200
lib_deps =
    adafruit/Adafruit NeoPixel @ ^1.11.0
    adafruit/DHT sensor library @ ^1.4.4
